# Support

Need help with Arillso projects? Here's how to get support.

## 📚 Documentation

Start with our comprehensive documentation:

**[guide.arillso.io](https://guide.arillso.io)** - Complete guides, examples, and API references

## 🔍 Self-Help Resources

Before asking for help, try these resources:

1. **Project README** - Check the specific project's README file
2. **CHANGELOG** - See if your issue is addressed in recent releases
3. **Closed Issues** - Search closed issues for similar problems
4. **Discussions** - Browse [GitHub Discussions](https://github.com/orgs/arillso/discussions)

## 💬 Community Support

### GitHub Discussions

For questions, ideas, and community support:

**[GitHub Discussions](https://github.com/orgs/arillso/discussions)**

- 💡 **Ideas** - Share feature requests
- 🙋 **Q&A** - Ask questions
- 📣 **Show and Tell** - Share your implementations
- 💬 **General** - Everything else

### GitHub Issues

For bug reports and specific technical issues:

1. Search existing issues first
2. Use issue templates when creating new issues
3. Provide reproduction steps
4. Include version information

## 📧 Direct Contact

For private or sensitive matters:

- **General inquiries**: hello@arillso.io
- **Security issues**: security@arillso.io (see [SECURITY.md](SECURITY.md))
- **Business inquiries**: hello@arillso.io

## 🐛 Bug Reports

When reporting bugs, include:

- **Version** of the tool/collection
- **Operating System** and version
- **Steps to reproduce** the issue
- **Expected behavior** vs actual behavior
- **Error messages** or logs
- **Minimal reproduction** (if possible)

## 💡 Feature Requests

When requesting features:

- Check if it already exists in newer versions
- Search for existing feature requests
- Describe the problem you're trying to solve
- Explain why this would be useful to others
- Consider contributing the feature yourself!

## ⏱️ Response Times

We're a small team, so please be patient:

- **Critical Security Issues**: 24-48 hours
- **Bug Reports**: 3-5 business days
- **Feature Requests**: Reviewed monthly
- **Questions**: Best effort, usually within a week
