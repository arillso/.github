# Arillso

> The simple, flexible, robust and powerful automation platform for infrastructure management.

## 👋 Welcome

Arillso provides production-ready Ansible collections, GitHub Actions, and container images for modern infrastructure automation. Our tools are designed for reliability, security, and ease of use across Linux and Windows environments.

## 🚀 Projects

### Ansible Collections

- **[arillso.system](https://github.com/arillso/ansible.system)** - System configuration and management (access, packages, network, firewall, logging)
- **[arillso.container](https://github.com/arillso/ansible.container)** - Container orchestration (Docker, K3s, Helm, Fleet, Tailscale)
- **[arillso.agent](https://github.com/arillso/ansible.agent)** - Monitoring and observability agents (Grafana Alloy, DigitalOcean Agent)

### Container Images

- **[arillso/ansible](https://github.com/arillso/docker.ansible)** - Alpine-based Ansible container with Mitogen optimization

### GitHub Actions

- **[action.playbook](https://github.com/arillso/action.playbook)** - Run Ansible playbooks in GitHub Actions workflows

### Go Libraries

- **[go.ansible](https://github.com/arillso/go.ansible)** - Go module for programmatically executing Ansible playbooks
